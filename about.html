Professional Biography

I am a dedicated researcher at the University of Messina, Italy, specializing in the development of advanced machine learning models for controlling upper limb movements through surface electromyographic signals. I hold a Master of Science in Computer Engineering from Addis Ababa University, and my undergraduate degree in Electrical and Computer Engineering, with a focus on Computer Engineering, was earned at Arba Minch University in Ethiopia. Currently, I am working on a cutting-edge research grant titled "Development of Machine Learning Models for Controlling Upper Limb Movements Using Surface Electromyographic Signals." This project blends my deep passion for both machine learning and biomedical engineering to create solutions with real-world implications for rehabilitation.

Projects & Software Development

Qubee-nlp: Afaan Oromoo Natural Language Processing Toolkit

An open-source Natural Language Processing toolkit for Afaan Oromoo, providing comprehensive tools for processing, analyzing, and understanding Afaan Oromoo text using the Qubee script.

pip install qubee-nlp GitHub: Qubee-nlp Documentation: qubee-nlp.readthedocs.io
Core Features:
Text Validation Tokenization Normalization Stemming POS Tagging Stopword Removal Syllabification Corpus Command Line Interface

Purpose: Designed for researchers, developers, and institutions working on Afaan Oromoo language technologies. This toolkit addresses the need for specialized NLP tools for low-resource languages and supports ongoing research in hate speech detection and sentiment analysis for Afaan Oromoo and related languages.

Documentation: Complete documentation is available at https://qubee-nlp.readthedocs.io

Afaan Oromoo Hateful Memes Detection on Social Media

This ongoing research project focuses on developing deep learning models to detect hateful content in Afaan Oromoo memes on social media platforms. The project utilizes NLP techniques for text extraction and computer vision for image analysis.

Technologies: Python, Deep Learning, Computer Vision, Natural Language Processing, Qubee-nlp toolkit

Development of Machine Learning Models for Controlling Upper Limb Movements

University of Messina Research Grant focused on building machine learning and deep learning models for upper limb movement control using surface electromyographic (sEMG) signals.

Applications: Rehabilitation robotics, assistive technologies, human-machine interaction systems
